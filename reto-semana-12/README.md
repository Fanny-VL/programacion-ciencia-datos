# Reto Semana 12 - Analizador de Plataforma de Streaming Musical

## Descripción

Sistema de análisis de datos de una plataforma de streaming musical utilizando Pandas para explorar patrones de escucha, popularidad de canciones y comportamiento de usuarios.

## Temas trabajados

* Manipulación de DataFrames
* Limpieza y transformación de datos
* Estadística descriptiva
* Agrupaciones y agregaciones
* Análisis de popularidad musical
* Generación de métricas y reportes

## Herramientas utilizadas

* Python
* Pandas
* Jupyter Notebook
