# Reto Semana 08 - MeteoSense Analytics

## Descripción

Análisis de datos meteorológicos utilizando NumPy para procesar información de sensores distribuidos en estaciones de monitoreo de la Ciudad de México.

## Temas trabajados

* Exploración de arrays multidimensionales
* Indexación y slicing
* Estadísticas descriptivas
* Operaciones vectorizadas
* Agregaciones por ejes
* Análisis de métricas ambientales

## Herramientas utilizadas

* Python
* NumPy
* Jupyter Notebook
